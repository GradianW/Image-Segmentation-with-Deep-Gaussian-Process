# Folder Presentasi / Seminar Tugas Akhir (TA)

Folder ini digunakan khusus untuk menyimpan materi presentasi (PPT / Slide Beamer) beserta aset gambar untuk Seminar Tugas Akhir.

## Struktur Folder

- **`01_Seminar_TA_1/`** — **Seminar TA Pertama (Akhir Semester Ini)**
  - **Cakupan Materi**: Bab 1 (Pendahuluan), Bab 2 (Tinjauan Pustaka / Dasar Teori), dan Bab 3 (Metodologi Penelitian).
  - **`figures/`**: Menyimpan grafik, diagram alir, dan ilustrasi untuk slide Seminar 1.

- **`02_Seminar_TA_2/`** — **Seminar TA Kedua (Akhir Semester Depan)**
  - **Cakupan Materi**: Bab 4 (Hasil & Pembahasan) dan Bab 5 (Kesimpulan & Saran), serta ringkasan Bab 1–3.
  - **`figures/`**: Menyimpan hasil visualisasi eksperimen dan evaluasi untuk slide Seminar 2.
